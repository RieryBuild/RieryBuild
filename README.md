# Halo, gue Riery 👋

Builder kecil-kecilan dari Indonesia. Suka bikin tool yang simpel tapi kepake —
terutama seputar **Web3/BSC**, **otomasi browser**, dan **utilitas sehari-hari**.
Prinsipnya: satu file kalau bisa, nol dependensi kalau bisa, yang penting jalan dan jelas.

## 🚀 Projek

| Projek | Buat apa |
|---|---|
| [inject-js-tool](https://github.com/RieryBuild/inject-js-tool) | Inject JavaScript ke website lewat Chrome (Puppeteer) — ada CLI + GUI ramah buat orang awam |
| [fcfs-countdown](https://github.com/RieryBuild/fcfs-countdown) | Countdown jadwal mint/claim FCFS — beep + badge LIVE pas jam buka |
| [bnb-gas-watch](https://github.com/RieryBuild/bnb-gas-watch) | Cek gas BSC live + estimasi biaya transaksi dalam BNB & rupiah |
| [wita-time](https://github.com/RieryBuild/wita-time) | Konversi zona waktu Indonesia WIB / WITA / WIT — library + CLI tanpa dependensi |
